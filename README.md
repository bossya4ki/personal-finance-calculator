# Калькулятор личных финансов

Консольное приложение на Python для учёта доходов и расходов.

## Запуск

Python 3.10+. Команда `python src/main.py`.

## Использование

1 добавляет доход, 2 — расход, 3 показывает список, 4 — баланс, 0 — выход. Вводите сумму, категорию и дату ГГГГ-ММ-ДД.

## Функционал

Учёт операций, валидация суммы и даты, сохранение в JSON и расчёт баланса. В планах фильтрация по периоду.
